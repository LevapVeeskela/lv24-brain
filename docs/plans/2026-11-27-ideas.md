# 0.28 Ideas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ship an agent-first Ideas/TODO layer: engine `0.28.0` (records, CLI, MCP, session brief, local API) and desktop `1.8.0` (Ideas list, editor, reminders, calendar).

**Architecture:** one Markdown file per idea under `projects/<project_id>/ideas/`, modeled on `Decision`; the engine owns validation, storage, indexing, CLI/MCP/API; the session brief is a capped best-effort block; the desktop is a view that talks to the local API, with a Rust reminder scheduler while the tray is alive.

**Tech Stack:** Go 1.27 engine (stdlib + existing SQLite FTS5), Tauri 2 + React 19 + MobX + TypeScript, VitePress docs.

**Spec:** `docs/spec-0.28-ideas.md` (the authority; the plan argues from it). The contract produced by WS0 is authoritative for exact signatures after it lands.

## Global Constraints

- Versions: engine `0.28.0`, desktop `1.8.0`; data schema stays `1`; index schema `11`.
- No new engine runtime dependencies. Desktop adds only `tauri-plugin-notification` (plus its capability).
- Local/git modes first; server mode returns `ErrUnsupported` for ideas.
- One file per idea: `projects/<project_id>/ideas/idea-<date>-<slug>-<ULID>.md`; redaction and limits (`title` 200, body 1 MiB, tags 10) apply.
- Statuses `open|doing|done|dropped|someday`; exactly one of `due_at` (RFC3339+offset) or `due_date` (YYYY-MM-DD); all-day anchor 09:00 local.
- `remind_before_minutes` is concrete; absent/0 = due-time only; no hidden inheritance.
- Project ids validated against `registry.json`; default = cwd project; fallback `personal`; never invent a project.
- Session block: global ordered current-project-first, max 3 items, ≤700 chars, `source=startup` only, best-effort, no body text.
- `.ics` is a file export, not a live subscription.
- Docs must be updated in en/ru/zh; no paid services, no telemetry, no cloud sync.

## Review Focus

1. **Hook timeout:** `brain session start` already exceeds 10 s on some Claude starts; the ideas query must not add a second bootstrap or a `Findings` pass.
2. **Timezone/all-day:** `due_date` must not shift with travel; `due_at` renders local; all-day reminders anchor at 09:00; DST boundaries.
3. **Project tagging:** cwd default, registry validation, `personal` fallback, and no project invented from text.
4. **Conflict visibility:** a conflicted/unparsable idea file must appear as a problem row, not vanish; other ideas stay usable; the file is preserved.
5. **Reminder dedupe:** no duplicate toast for the same `{idea, due, trigger}`; quiet hours; missed digest on launch; Quit means no reminders.

## Review and Merge Protocol

1. Record BASE before each dispatch; implementer commits on its worktree branch.
2. Implementer report: status, commits, tests, concerns; no subagents.
3. Reviewer gets the task brief, report and a diff package (BASE..HEAD); returns spec ✅/❌ + quality ✅/❌.
4. Fix loop: resume the implementer for Critical/Important findings; re-review the fix diff.
5. Merge order: engine → desktop → docs; resolve conflicts in the owning worktree, then rerun the gate.
6. Final: full engine tests, desktop `npm run check` + cargo checks, docs build, cross-repo smoke; then release notes and version bumps.
